项目伴侣（Windows 便携版）
========================================

这是一个本地小工具：把项目像照片一样挂在绳子上，点开能看到今天/近 7 天
动了哪些文件、哪些文件堆了旧版本，并把旧副本收进 _versions 里随时可还原。
数据只在本机，不上传任何地方。

一、怎么跑起来
1) 装 Python 3.9 或更高（python.org 官方安装包，安装时勾选 Add python.exe to PATH）
2) 双击 start_panel.bat
   会弹一个黑窗口（服务进程，别关）和一个浏览器页面。
   页面地址：http://127.0.0.1:8899
3) 第一次是空板：点右上角“重新扫描”前，先登记项目（二选一）
   A. 命令行：python project_panel.py --add "D:\工作\某项目" --add "E:\资料\另一个"
   B. 直接编辑同目录的 panel_config.json，把路径写进 "projects" 数组
      （Windows 路径要写双反斜杠，如 "D:\\工作\\某项目"）

二、日常怎么用
· 挂绳页：一张宝丽来 = 一个项目；红章 = 搁置多少天；点开看详情。
· 变化页：只列最近动过的文件（今天 / 近 7 天），不铺全量清单。
   每行：时间、文件、新建还是改动、旧版本 ×N。
· 点文件名：直接在资源管理器里定位到那一份。
· 点“去整理”：看这个文件的版本堆叠，绿底是最新，其他是副本；
   “归档旧副本”会把旧副本挪进 <项目>\_versions\<时间戳>\，最新那份不动，
   同时在 manifests\ 里留一份可还原清单。

三、几个 Windows 上的注意事项
· 别把本工具放进 C:\Program Files 之类需要管理员权限的目录，放 D:\ 或桌面都行。
· 只登记你真的要盯的目录。整块 D:\ 或整个“文档”都加进来，第一次扫描会很慢；
   代码里已经跳过 node_modules / .git / venv / __pycache__ / dist / build 等。
· 单个项目超过 1.5 万个文件会自动切成“轻量统计”，不逐个读内容，详情页只给
   最近 800 条文件，避免卡死。
· 网络盘 / OneDrive 在线文件：stat 很慢，建议只加本地盘目录。
   OneDrive“按需文件”可能读不到内容，缩略图和哈希会失败但不影响列表。
· 路径超过 260 字符时 Python 可能读不到，建议项目目录别套太深。
· 端口被占用会自动顺延（8899→8900…），如果黑窗口打印的地址不是 8899，
  以窗口里那行为准。
· .panel_token 是本机令牌文件，别删；删了下次启动会重新生成，旧页面要刷新一次。

四、目录说明
project_panel.py   服务端 + 接口（Flask 都不用装，纯标准库）
project_map.py     扫描/版本链/隔离区/清单还原
panel.html         看板页面
panel_config.json  项目清单
manifests\         每次归档/清理的还原清单
_versions\         归档的旧副本（在各自项目目录里）

五、做不到的部分
· 没有实时监听（不装 watchdog/FSEvents），点“重新扫描”或等缓存过期才更新；
  这是刻意选择：agent 是成批写文件的，实时事件只会变成噪声。
· 归因（哪个 agent 改的）依赖 DSH/WorkBuddy/Trae 的活动日志；Windows 上没有这些
  日志时统一显示“未知来源”，不影响变更和版本功能。
